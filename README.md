# Train in the Mountains

A silent 99-second Three.js recreation of Durango & Silverton locomotive No. 481 at Cement Wall.

Open [index.html](index.html) on GitHub, select **Download raw file**, and open the saved file in Chrome. The demo runs offline and requires WebGL 2.

Press **Play** to watch from the reference camera. Use **Move camera** to look around, Shift-drag to slide, and scroll to dolly. **Reset camera** returns to the reference view at the current timecode.

The terrain includes photographic detail from [Joe Fusco’s Cement Wall footage](https://www.youtube.com/watch?v=wvAqn_kCSss&t=401s). Additional CC0 assets come from Poly Haven ([rock texture](https://polyhaven.com/a/rock_face), [rock scan](https://polyhaven.com/a/rock_face_01), [snow](https://polyhaven.com/a/snow_01), [fir](https://polyhaven.com/a/fir_tree_01), and [pine](https://polyhaven.com/a/pine_tree_01)). The Three.js MIT license is included in the HTML.
